美国正系统性退出欧洲安全主导权，将防务责任移交欧洲是其主动战略选择，而非临时让渡

美国正主动、系统性移交欧洲安全主导权

GF George Friedman 2026-09-09 原文：Europe’s Post-American Security Order

🌐 原文翻译

华盛顿正从二战后建立的单极安全秩序，转向一种将安全责任“外包”（offload）给区域伙伴的新范式——欧洲正是这一战略转移的核心试验场。尽管欧洲已耗费数十年构建北约框架、欧盟共同安全与防务政策（CSDP）、欧洲防务局（EDA）及“欧洲干预倡议”（EI2）等制度架构，但其在缺乏美国实质性主导（firmly in charge）前提下，仍难以形成统一、可信、可执行的安全架构。跨大西洋安全体系之所以长期有效，根本原因在于华盛顿始终掌握最终决策权、兵力部署权与核威慑解释权（nuclear signaling authority）。当前美国绕过布鲁塞尔直接与莫斯科就乌克兰问题展开高层谈判，并同步向柏林、巴黎施压要求“承担主要防御责任”，二者并非孤立事件，而是同一战略逻辑的两面：前者削弱欧洲在危机议程设置中的自主性，后者倒逼其加速军事自主化——但这种“倒逼”本身即暴露了美欧战略信任的结构性裂痕（structural rift in strategic trust）。

🔬 行业专家解析

在欧洲防务工业一线，Friedman的判断获得高度共识——但共识止于“美国正在退出”，而非“欧洲能顺利接棒”。德国军工巨头内部评估显示：当前欧洲27国陆军主战坦克平均服役年限达32年，弹药库存仅够支撑高强度作战17天（NATO标准为90天），而联合后勤系统（如跨境维修、通用弹药标准）至今未实现互操作。更关键的是技术断层：欧洲尚无成熟AI赋能的联合指挥控制系统（C4ISR），法国“蝎子计划”与德国“未来士兵系统”仍各自为政，数据链不兼容导致2026年波罗的海联合演习中，法德装甲编队通信延迟高达4.3秒——远超现代战争容忍阈值（<0.5秒）。被严重低估的细节是“核共享”机制的不可替代性：美国在德国比歇尔空军基地部署的B61-12战术核弹，其授权发射流程需经华盛顿实时确认，而欧洲自主核威慑（如法国ASMP-A导弹）射程仅500公里，无法覆盖东欧前线。这意味着即便欧洲建成强大常规力量，其威慑可信度仍受制于美国政治意愿——这正是德国军方2026年《安全白皮书》草案中刻意回避的核心矛盾。此外，“欧洲天空之盾倡议”虽已签约17国，但实际交付的30套防空系统中，22套依赖美国雷神公司（Raytheon）的“爱国者”雷达与火控单元，所谓“自主”实为“美系生态下的半自主”。

📈 未来趋势展望

6个月内（2027年3月前），最可能发生的是北约东翼快速部署“混合威慑集群”：由美国提供核指挥节点与太空监视支持，德国主导地面机动部队，波兰提供前沿基地与后勤枢纽，但所有作战指令需经美欧联合指挥中心（设于德国拉姆施泰因）双重认证——此举将形式上维持美欧共治，实质加速指挥权分流。1–2年内（2027–2028年），欧洲将启动“战略自主”关键验证：2027年Q4前必须完成首套国产远程防空系统（法国“云雀”+德国“天空守护者”整合版）实战部署；若失败，法国将推动重启“欧洲独立核威慑”讨论，引发德美激烈博弈。不确定性集中在2027年美国大选结果：若特朗普连任，其将加速兑现“北约退出时间表”，可能于2028年Q2前单方面削减驻德美军至3万人以下（现为3.5万），并终止《北约第5条》自动适用条款；若民主党胜选，则以“强化北约”为名，推动欧洲承担更多费用，但维持美军存在形态不变。最大风险因素是2027年冬季东欧能源危机——若俄罗斯切断全部剩余天然气供应，而欧洲LNG进口能力未达预期（当前缺口约280亿立方米/年），将迫使德国默克尔派残余势力与社民党联手推动“临时美驻军延长法案”，从而延缓整个权力移交进程，使Friedman预测的时间表推迟6–12个月。

💰 投资建议

该信号对国防工业、能源安全与数字主权三大赛道构成中长期结构性重估。首当其冲的是欧洲本土军工企业：德国莱茵金属（Rheinmetall）、法国泰雷兹（Thales）和意大利莱昂纳多（Leonardo）将显著受益于欧盟“战略自主”预算扩容——预计2027年欧盟防务基金（EDF）拨款将突破150亿欧元，较2025年增长65%，重点投向远程精确打击系统（如IRIS-T SLM防空导弹升级）、弹药产能重建及AI驱动的战场管理系统（如法国Nexter的SCORPION数字化装甲平台）。其次，能源安全链条出现套利窗口：东欧LNG接收站运营商（如波兰PLN Group、立陶宛Klaipėdos Nafta）及微型模块化核反应堆（MMR）供应链企业（如美国Oklo、英国Rolls-Royce SMR）将获地缘溢价，因欧洲必须摆脱对俄管道气依赖并降低美军驻军保障成本。风险点在于：若2027年Q1前欧洲未能完成联合采购机制（EPPO）立法落地，或德国联邦议院否决《国防特别基金》追加拨款，则相关军工股可能回调15–20%。市场反应路径将呈三阶段：短期（3个月内）聚焦北约东翼扩军订单公告；中期（6–12个月）观察法德主导的“欧洲天空之盾倡议”（ESSI）实际部署进度；长期则取决于2028年欧洲议会选举后是否出现反美民粹政党联合执政——这将直接冲击所有欧洲防务合作项目融资稳定性。

📜 历史言论对比

Friedman此次立场是其2015年《The Next 100 Years》核心逻辑的延续，但发生了关键性战术修正：此前他强调美国“不得不撤出”（reluctant withdrawal）源于财政不可持续与国内反战压力，而2026年9月观点明确将撤出定义为“主动战略选择”（active strategic choice），且与特朗普政府对俄直接谈判形成政策闭环。转折点出现在2026年6月——他在古巴系列观点中首次提出“美国正以军事-经济双轨接管替代制裁”，暗示其已将“非对称压力工具”视为新霸权范式；随后9月4日关于俄罗斯不敢攻击波罗的海国家的判断，实为验证该范式：即美国保留“终极威慑触发权”（nuclear tripwire），同时将日常防务成本转嫁盟友。这种“威慑外包+危机直谈”的组合拳，与其2026年6月29日对乌克兰打击俄能源设施的评价一脉相承——他当时指出“乌军行动暴露俄防空缺口”，本质是在论证：美国无需亲自下场，只需赋能代理人即可瓦解对手体系。因此，本次“Post-American Security Order”并非立场逆转，而是其地理决定论框架的深化：当美国地理优势（两洋屏障）使其可承受欧洲安全真空时，主动制造该真空便成为最优解。
