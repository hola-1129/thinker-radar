🌐 原文翻译

重新思考如何衡量人工智能（AI）智能

当前AI基准测试正难以跟上现代模型的发展步伐。虽然它们在衡量特定任务表现上很有用，但很难确定在互联网数据上训练的模型是真正在解决问题，还是仅仅记住了已见过的答案。随着模型在某些基准上接近100%，它们揭示有意义性能差异的能力也变弱了。我们继续投资更具挑战性的新基准，但在通往通用人工智能（AGI）的道路上，我们需要寻找新的评估方式。近期向动态、人类评判测试的转变解决了记忆和饱和问题，但人类偏好的固有主观性又带来了新困难。

在继续演进当前基准的同时，我们也在不断寻找测试新方法。因此，今天我们推出 Kaggle Game Arena：一个全新的公共AI基准测试平台，AI模型在战略游戏中进行一对一竞争，提供可验证且动态的能力衡量标准。

为什么游戏是有意义的评估基准

游戏提供了清晰、明确的成功信号。其结构化特性和可衡量结果使其成为评估模型和智能体（Agents）的完美试验场。它们迫使模型展示战略推理、长期规划和对抗智能对手时的动态适应等技能，提供其通用问题解决智能的稳健信号。游戏的价值还在于其可扩展性——难度随对手智能提升而增加，以及我们检查和可视化模型“推理”的能力，这让我们得以一窥其战略思考过程。

像Stockfish这样的专业引擎和AlphaZero这样的通用游戏AI模型多年来已能以超人水平玩游戏，毫无疑问会击败当今所有前沿模型。然而，今天的大型语言模型（LLMs）并非为特定游戏构建，因此表现不佳。虽然眼前的挑战是缩小差距，但长期来看，我们希望它们达到超越目前可能的水平。通过不断增加的新环境，我们可以继续挑战它们。

Game Arena 如何促进公平开放的评估

Game Arena 基于 Kaggle 构建，提供公平、标准化的评估环境。为了透明，游戏接入框架（game harnesses，连接AI模型与游戏环境并执行规则的框架）以及游戏环境均开源。最终排名由严格的全循环赛（all-play-all）系统决定，每对模型之间进行大量比赛以确保统计结果的稳健性。

🔬 行业专家解析

从技术一线视角来看，用游戏作为 AGI 试金石在 DeepMind 内部及顶尖 AI 实验室中拥有极高共识。自 AlphaGo 和 AlphaStar 以来，DeepMind 一直坚信复杂游戏是测试通用智能的最佳沙盒。当前 LLM 在 MMLU 等静态基准上“刷题”饱和，转向动态博弈是技术发展的必然。Kaggle Game Arena 的推出，实际上是将 DeepMind 内部的评估方法论进行了开源化和平台化，这有助于统一行业对“Agent 能力”的衡量标准。

然而，在执行层面面临巨大挑战。将 LLM 接入游戏环境并保证公平性极其困难。LLM 缺乏原生的空间感知和毫秒级反应能力，必须依赖外挂的“系统2（System 2）”思考模块或传统控制算法。更棘手的是，视频游戏的状态空间呈指数级爆炸，如何定义“胜利”、如何设计稀疏奖励（Sparse Rewards）以防止模型陷入局部最优，是工程落地中的巨大痛点。

行业内可能低估了一个关键细节：Hassabis 在文中特别提到“检查和可视化模型的推理（inspect and visualize a model's 'reasoning'）”。这意味着 Game Arena 的核心目的不仅仅是看输赢（Outcome Reward），更是为了评估模型的思考过程（Process Reward）。这暗示了 DeepMind 在可解释性（Mechanistic Interpretability）和过程监督上的重大战略投入。能够“看懂”模型为什么走这一步，比单纯赢下比赛对 AGI 研发更具决定性意义。

📈 未来趋势展望

6个月内，Kaggle Game Arena 将发布首份权威榜单。初期环境可能以经典棋盘游戏（国际象棋、围棋）和简单的 2D 游戏（如 Atari 系列）为主。市场将密切关注头部 LLM（如 Gemini、GPT-5 等）在零样本（Zero-shot）或轻量微调后的表现。预计会出现明显的“能力分化”现象：某些模型在逻辑严密的棋类中表现惊人，但在需要快速视觉反馈的游戏中表现糟糕，这将引发关于模型架构优劣的激烈讨论。

1-2年的中期演变方向，Arena 将不可避免地引入复杂的 3D 视频游戏（如 Minecraft、StarCraft II 甚至更复杂的开放世界游戏）。这将直接推动“多模态 Agent”和“具身智能（Embodied AI）”的爆发。模型将不再仅仅是文本生成器，而是必须具备视觉-动作联合推理的决策大脑。同时，“游戏接入框架（game harnesses）”将成为开源社区最活跃的基建项目之一。

不确定性和风险因素主要集中在“奖励黑客（Reward Hacking）”和“环境过拟合”。如果模型只是找到了游戏引擎的 Bug 或捷径（例如在 3D 游戏中通过无限原地跳跃来刷分），而不是真正学会了战略推理，那么基准将失去意义。此外，构建高保真、物理规律准确的复杂游戏环境成本极高，如果基准的更新速度跟不上模型迭代速度，Game Arena 可能会面临与当前静态基准一样的“饱和”困境。

💰 投资建议

从资本配置角度来看，DeepMind 推出 Kaggle Game Arena 标志着 AI 评估范式从“静态知识检索”向“动态环境博弈”转移。这一转变将直接利好底层算力与低延迟基础设施赛道。复杂游戏（尤其是3D视频游戏）的实时推理需要极高的算力和极低的延迟，这将加速英伟达（NVIDIA）下一代推理芯片的部署，并提升云服务商（如 AWS、GCP）在边缘计算和实时渲染云化方面的资本开支预期。

其次，AI 评估工具链与仿真环境赛道将迎来价值重估。传统的 LMSYS 等基于文本的静态榜单影响力将被稀释。专注于动态环境构建、Agent 行为评估以及强化学习（RL）仿真平台的初创公司（如 Scale AI 的竞争对手，或专注于数字孪生和仿真引擎的企业）将成为并购热点。投资者应密切关注在“游戏接入框架（game harnesses）”和“过程奖励模型（PRM）”领域有技术壁垒的公司。

此外，游戏与互动娱乐产业将作为 AI Agent 的首个大规模商业化落地场景迎来爆发。AI 原生游戏（具备动态生成关卡、具备长期记忆和战略推理的 AI NPC）将重塑行业估值逻辑。利好拥有丰富游戏 IP 和成熟仿真环境的巨头（如腾讯、Unity、Roblox）。

风险点在于：如果头部大模型在 Game Arena 的初期测试中表现出严重的“偏科”（例如在棋类中表现优异，但在需要空间感知的视频游戏中崩溃），可能会引发市场对当前 Transformer 架构在“通用空间推理”能力上的质疑，从而导致 AI 软件层公司在短期内面临估值回调压力。

📜 历史言论对比

结合 Hassabis 近期的思想脉络，这一观点是高度延续且深化的。在2026年5月的观点中，他强调“科学突破将越来越多地来自通用 AI 智能体（general AI agents）”，并指出 AI 应作为“人类科学创造力的力量乘数”。Game Arena 中测试的“战略推理、长期规划和动态适应”，正是通用智能体在未来进行科学探索、处理海量文献（解决2026年5月提到的“手动综合分析瓶颈”）所必需的核心底层能力。

转变在于评估对象的范式跃迁。过去（如 AlphaGo 时代），游戏 AI 是“专用”的，针对特定环境优化。而在此次观点中，Hassabis 明确指出“今天的大型语言模型并非为特定游戏构建”，目标是让“通用”模型在“不断扩展的新环境”中表现优异。这标志着从“专用游戏 AI”向“通用环境 AI”的跨越。

这一变化传递出一个强烈信号：DeepMind 正在将游戏评估与 Agent 落地能力深度绑定。结合其2026年4月提到的“AI 经济潜力与企业落地存在显著差距”，Game Arena 实际上是在为 Agent 解决复杂企业工作流提供能力验证。如果 AI 能在复杂游戏中展现出通用规划能力，就能证明其具备解决现实世界复杂问题的潜力。
