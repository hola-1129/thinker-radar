动态人工评测虽优于静态基准，但主观性带来新问题，需替代评估方法。

弃用静态基准，以动态游戏对抗重塑AGI评估体系

DH Demis Hassabis 2025-10-23 原文：Rethinking how we measure AI intelligence
🎯
核心论点
弃用静态基准，以动态游戏对抗重塑AGI评估体系
时间维度
中期（6-18个月）
🌐 原文翻译

当前的AI基准测试（AI benchmarks）已难以跟上现代模型的发展步伐。尽管它们在衡量特定任务性能方面有所帮助，但我们很难判断在海量互联网数据上训练的模型，究竟是在真正解决问题，还是仅仅记住了它们已经见过的答案（即数据污染）。当模型在某些基准测试上的得分接近100%时，这些测试在揭示有意义的性能差异方面就变得不再有效。我们持续投资开发更具挑战性的新基准，但在通往通用人工智能（AGI）的道路上，我们必须不断探索新的评估方式。近期向动态、人类评判测试（dynamic, human-judged testing）的转变，虽然解决了记忆和分数饱和的问题，但又因人类偏好固有的主观性（subjectivity of human preferences）而带来了新的困难。

在继续完善现有AI基准的同时，我们也在不断尝试测试评估模型的新方法。因此，我们今天推出了Kaggle Game Arena：一个全新的公开AI基准测试平台。在这里，AI模型在战略游戏中进行头对头（head-to-head）的竞争，从而为其能力提供可验证且动态的衡量标准。

游戏作为评估基准具有深远意义。游戏能提供清晰、无歧义的成功信号。其结构化的性质和可衡量的结果，使其成为评估模型和智能体（agents）的完美测试平台。游戏迫使模型展示多种技能，包括战略推理（strategic reasoning）、长期规划（long-term planning）以及针对智能对手的动态适应（dynamic adaptation），从而为其通用问题解决智能提供稳健的信号。游戏作为基准的价值还在于其可扩展性——难度会随着对手智能的提升而增加——以及我们能够检查和可视化模型的“推理”过程，从而一窥其战略思考过程。

尽管像Stockfish这样的专用引擎和像AlphaZero这样的通用游戏AI模型多年来一直能以超人水平玩游戏，并毫无疑问地击败所有前沿模型，但今天的大语言模型（LLMs）并非为专精任何特定游戏而构建，因此表现相去甚远。模型面临的直接挑战是缩小这一差距，而从长远来看，我们希望它们能达到超越目前可能性的游戏水平。随着无限增加的新颖环境，我们可以继续对它们提出更高挑战。

Game Arena建立在Kaggle之上，旨在为模型评估提供公平、标准化的环境。为了保持透明度，游戏线束（game harnesses，即连接AI模型与游戏环境并执行规则的框架）以及游戏环境本身均已开源。最终排名由严格的循环赛（all-play-all）系统决定，每对模型之间进行大量比赛，以确保结果在统计学上的稳健性。

🔬 行业专家解析

在AI研究前沿，静态基准失效已是普遍共识，“刷榜”和“数据污染”让传统评测失去意义。Hassabis提出用游戏和动态对抗替代，在学术界和顶尖实验室（如OpenAI、Anthropic）中具有极高共识。这不仅是评测方法的改变，更是强化学习（RL）和系统2（System 2）推理回归主流视野的强烈信号。业界普遍认同，只有在具有明确奖励信号和动态博弈的环境中，才能真正测出模型的“智能”而非“记忆力”。

然而，在执行层面存在巨大的工程挑战。将大语言模型（LLM）无缝接入游戏环境并实现低延迟的API交互是一个复杂的系统工程。此外，游戏环境的复杂度设计至关重要：太简单无法区分前沿模型，太复杂（如《星际争霸》）则计算成本过高且奖励信号稀疏。如何构建一个“难度梯度平滑”且涵盖多种认知维度的游戏集，是Kaggle Game Arena能否长期保持权威性的核心难点。

被外界严重低估的关键细节在于Hassabis提到的“检查并可视化模型的推理过程”。这暗示了DeepMind正在将游戏对抗与可解释性（Interpretability）研究深度结合。通过观察模型在游戏中的决策树和注意力分布，研究人员可以逆向工程其内部表征。这种“白盒化”评测比单纯看胜率对AGI安全和对齐（Alignment）研究更有价值，它为解决AI黑盒问题提供了一条极具操作性的路径。

另一方面，业界可能高估了仅靠扩大模型参数或微调就能让LLM在Game Arena中迅速逼近AlphaZero水平的可能性。自回归生成机制天生缺乏真正的“前瞻搜索（lookahead）”能力。短期内，LLM在复杂战略游戏中的表现可能依然糟糕，要实现突破，大概率需要模型架构的根本性创新，例如将Transformer与蒙特卡洛树搜索（MCTS）等规划模块深度耦合。

📈 未来趋势展望

在未来6个月内，Kaggle Game Arena将迅速成为业界新的“必争之地”和营销焦点。各大模型厂商（如OpenAI、Anthropic、Meta）将投入专门的工程团队优化模型在Game Arena中的表现。我们可能会看到针对游戏环境特化的“推理时计算（Inference-time compute）”优化技术大量涌现，类似o1的推理模型将在游戏榜单上展开激烈厮杀，动态对抗排名将取代静态跑分成为大模型发布会的核心卖点。

在1-2年的中期演变中，基于游戏的动态评测将向外溢出，催生“行业级仿真对抗基准”。例如，金融领域会出现基于真实市场数据的“交易博弈Arena”，医疗领域会出现“诊断对抗Arena”，自动驾驶领域会普及“极端路况博弈Arena”。评估AI不再看静态分数，而是看其在特定行业仿真环境中的“胜率”和“收益”。这将极大加速AI在垂直行业的规模化落地，有望解决Hassabis在2026年4月提到的“仅25%企业成功规模化应用”的采用率瓶颈。

技术架构方面，1-2年内模型将发生显著演变。为了让LLM在Game Arena中战胜专用引擎，纯粹的自回归Transformer将向“Transformer + 搜索/规划模块”（如结合MCTS的System 2架构）演进。DeepMind可能会开源或发布专门针对长程规划优化的新型Agent架构，推动行业从“快思考”向“慢思考”范式转移。

最大的不确定性和风险因素在于“古德哈特定律（Goodhart's Law）”的再次应验。如果Game Arena成为唯一的核心指标，模型可能会通过利用游戏引擎的漏洞（bug exploiting）或过拟合特定游戏的奖励函数来获得高分，而非真正提升通用智能。此外，动态对抗评测的高昂算力成本可能进一步加剧大模型行业的寡头垄断，中小玩家将被彻底挤出前沿评测圈，导致AI创新生态的多样性受损。

💰 投资建议

从资本配置角度来看，评估范式的转移将直接重塑AI基础设施和算力调度的投资逻辑。从静态跑分转向动态对抗（如Game Arena），意味着推理侧（Inference）的算力需求将呈指数级上升。在动态博弈中，模型需要进行大量的前瞻搜索和实时决策，这将极大消耗推理算力。因此，提供高性能推理芯片、低延迟网络架构以及算力调度优化的公司（如Groq、Cerebras，以及NVIDIA的推理优化生态）将迎来显著的业绩催化，建议超配此类“卖水人”资产。

AI应用层与Agent赛道的估值逻辑将面临残酷重构。过去依赖静态榜单（如MMLU、HumanEval）讲故事、刷高分的应用层公司将面临估值挤压，因为静态分数不再能证明其实际解决复杂问题的能力。相反，真正具备战略推理和长期规划能力的Agent公司（如专注于自动化代码生成、复杂金融交易、供应链优化的初创企业）将获得估值溢价。投资者应重点关注那些在Kaggle Game Arena等动态环境中证明过自身实力的DeepMind生态内早期投资项目。

游戏引擎与仿真环境行业的跨界重估是另一个隐藏的投资主线。Hassabis明确将游戏定义为AGI的“完美测试床”，这将直接提升物理引擎、3D仿真环境（如NVIDIA Omniverse、Unity，以及各类数字孪生平台）的战略价值。它们不再仅仅是娱乐或工业可视化的工具，而是AGI的“训练场”和“考试院”。相关资产存在被科技巨头并购或价值重估的巨大机会。

风险提示方面，市场可能会短期内对“缺乏绝对客观评测标准”感到恐慌。动态评测的高门槛可能导致部分依赖刷榜营销的AI大模型公司（尤其是部分缺乏底层创新的大模型厂商）遭遇信任危机和估值回调。投资者需警惕那些无法在动态对抗环境中证明自身实力、仅靠参数规模堆砌的“伪前沿”模型，避免在估值泡沫破裂时受损。

📜 历史言论对比

从时间线来看，2025年10月的这一观点是Hassabis在2026年一系列关于“科学AI Agent”主张的底层逻辑支撑与前奏。2025年他提出用动态游戏评估AI的“战略推理和长期规划”，这直接为2026年5月他主张“科学突破将来自通用AI Agent”奠定了评测基础。如果没有可靠的动态评估体系来验证Agent的长期规划和动态适应能力，科学Agent在复杂研究中的可靠性就无从谈起。

这一观点也展现了Hassabis思想重心从“能力评估”向“社会责任”演进的转折点。在2025年10月，他高度关注如何准确衡量AI的“智力”和“解决问题”的能力；而到了2026年3月和4月，他的公开言论明显转向了AI的“社会影响”、“防止有害操纵”以及“负责任扩散”。这表明，随着Game Arena等评测体系证实了模型能力的飞速提升，他的思想重心自然从“如何造出和衡量更强的AI”转移到了“如何安全地部署和引导AI”。

此外，游戏评测与科学发现范式形成了完美的闭环。2025年强调游戏作为“完美测试床”来评估通用问题解决能力，这与2026年5月他指出的“科学瓶颈在于文献综合与分析”形成深刻呼应。游戏环境中的“动态适应”和“战略推理”能力，正是AI Agent在浩如烟海的科学文献中进行“手动综合与分析”所必需的核心技能。评测标准的升级，本质上是为了筛选出能真正突破科学瓶颈的超级Agent。
