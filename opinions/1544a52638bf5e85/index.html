🌐 原文翻译

重新思考我们如何衡量AI智能

当前的AI基准测试正努力跟上现代模型的发展步伐。尽管它们在衡量模型特定任务表现方面很有帮助，但很难确定在互联网数据上训练的模型是真正在解决问题，还是仅仅记住了它们已经见过的答案。随着模型在某些基准测试上接近100%的准确率，它们在揭示有意义的性能差异方面也变得不再有效。我们继续投资于新的、更具挑战性的基准测试，但在通往通用人工智能（AGI）的道路上，我们需要继续寻找评估的新方法。最近向动态的、人类评判的测试（human-judged testing）的转变解决了记忆和饱和问题，但反过来，由于人类偏好的固有主观性，又带来了新的困难。

虽然我们继续演进和追求当前的AI基准测试，但我们也一直在寻找测试评估模型的新方法。这就是为什么今天我们推出 Kaggle Game Arena：一个全新的公共AI基准测试平台，AI模型在此进行战略游戏的头对头（head-to-head）竞争，提供可验证的、动态的能力衡量标准。

为什么游戏是有意义的评估基准

游戏提供了清晰、明确的成功信号。其结构化的性质和可衡量的结果使其成为评估模型和智能体（agents）的完美试验场。它们迫使模型展示多种技能，包括战略推理、长期规划以及对抗智能对手时的动态适应，从而提供其通用问题解决智能的稳健信号。游戏作为基准的价值因其可扩展性而进一步增强——难度随着对手智能的提高而增加——以及我们检查和可视化模型“推理”的能力，这让我们得以一窥其战略思维过程。

像Stockfish这样的专业引擎和像AlphaZero这样的通用游戏AI模型多年来已经能够以超人水平玩游戏，毫无疑问会击败每一个前沿模型。然而，今天的大型语言模型（LLMs）并非为专门玩任何特定游戏而构建，因此它们玩得并不好。虽然模型面临的直接挑战是缩小这一差距，但从长远来看，我们希望它们能达到超越目前可能水平的游戏能力。并且随着不断增加的新颖环境集合，我们可以继续对它们提出更大的挑战。

Game Arena如何促进公平和开放的评估

Game Arena建立在Kaggle之上，为模型评估提供公平、标准化的环境。为了保持透明度，游戏线束（game harnesses，将每个AI模型连接到游戏环境并执行规则的框架）以及游戏环境本身都是开源的。最终排名由严格的全循环赛（all-play-all）系统决定，每对模型之间进行大量比赛，以确保结果具有统计学上的稳健性。

🔬 行业专家解析

在技术一线，业内对“苦静态刷榜久矣”有极高共识。LMSYS Chatbot Arena已经证明了动态人类偏好的价值，但Hassabis的突破在于敏锐指出了“人类主观性”的缺陷，并回归到“游戏/规则环境”这种具备客观奖励函数（Reward Function）的测试方法。这在强化学习（RL）和Agent开发者中是绝对的主流共识，因为游戏环境能提供无噪声的梯度信号。

从执行层面来看，从游戏智能到现实世界智能的泛化（Generalization）是最大挑战。游戏环境（如国际象棋、星际争霸）通常是完美信息或规则明确的，而现实世界的科学发现或商业决策充满信息不对称和规则模糊。如何设计既具备游戏般“客观可验证性”，又具备现实世界“复杂模糊性”的中间态环境（如虚拟科学实验室），是工程落地上的巨大难点。

被行业低估的关键细节是Hassabis特别强调的“game harnesses（游戏线束/连接框架）”的开源与标准化。这不仅仅是为了公平，更是在定义AI与外部环境交互的“标准协议”。谁掌握了Harness的标准，谁就掌握了Agent时代的“USB接口”定义权。这种底层协议的控制力，比单纯发布一个参数更大的模型更具长远的商业与生态价值。

📈 未来趋势展望

6个月内的短期演变中，Kaggle Game Arena将迅速成为开源和闭源模型的新“角斗场”。我们会看到各大厂商不仅卷语言模型，还会专门针对Game Arena的规则进行强化学习微调。基于游戏表现的排行榜将出炉，部分在传统NLP榜单上表现平平但在策略推理和长期规划上极强的模型将脱颖而出，改变现有的模型实力格局。

1-2年的中期方向上，Game Arena的“动态、客观、对抗”范式将溢出游戏领域，向更复杂的垂直行业仿真环境扩展。DeepMind可能会推出“虚拟生物实验室”或“模拟宏观经济系统”等新型基准。AI评测市场将彻底分化：静态测试退居二线用于基础能力摸底，而基于复杂环境交互的动态测试将成为衡量Agent商业落地能力的核心标准。

不确定性和风险因素在于“莫拉维克悖论”的变体：模型可能在高度结构化的游戏环境中表现出超人智能，但在缺乏明确奖励函数的现实模糊任务中依然表现糟糕（即“游戏智能”不等于“通用智能”）。此外，如果过度依赖游戏环境作为AGI的衡量标准，可能会导致AI研发资源过度向强化学习和博弈论倾斜，而忽视了常识推理、多模态感知和物理世界交互等同样关键的能力维度。

💰 投资建议

受影响的行业与赛道将发生显著转移。AI评测与对齐工具赛道、AI Agent基础设施、以及提供高保真仿真/游戏引擎的企业将迎来重估。静态榜单的失效意味着“刷榜”型AI初创公司的估值逻辑将被重塑，资金将加速向具备复杂环境交互、长期规划和动态适应能力的Agent公司倾斜。

具体的投资机会集中在提供高质量仿真环境和强化学习基础设施的标的。例如，游戏引擎巨头（如Unity、Epic Games/腾讯）可能从传统的“内容创作工具”被重新定价为“AI Agent训练场”；AI评测领域的头部企业（如Scale AI、Patronus AI）若能快速整合动态环境测试能力，将获得更高溢价。时间节点上，随着Kaggle Game Arena的开源，相关仿真环境API提供商和算力调度公司将在未来6-12个月内迎来实质性业务增长。

风险点在于市场短期内可能经历“评测标准混乱”的阵痛期。投资者需警惕那些仅依赖传统静态NLP榜单进行PR包装的AI公司估值回调。长期来看，掌握“环境定义权”和“裁判协议”的底层平台（如DeepMind通过Kaggle）将形成新的生态护城河，建议逢低布局具备强大生态整合能力的云与AI基础设施巨头（如Google/Alphabet）。

📜 历史言论对比

这一观点是Hassabis过往思想的延续与实质性深化。在2026年5月17日，他明确提出“科学突破将越来越多地来自通用AI Agent，而非狭窄的专用模型”，并强调AI应作为“人类科学创造力的力量乘数”。本次推出Game Arena，正是为了建立一套标准，来衡量Agent是否真正具备这种“通用问题解决智能”。这是从“呼吁Agent赋能”向“建立Agent能力验证标准”的跨越。

同时，这也回应了他此前的行业观察。在2026年4月21日，他曾指出“AI的经济潜力与企业实际落地之间存在显著差距（仅25%成功规模化）”。本次观点的转变在于，他意识到导致这一落地差距的核心原因之一，是现有的静态评估无法真实反映模型在复杂动态环境中的表现。因此，评估范式必须从“模型中心（Model-centric）”的静态做题，转向“Agent中心（Agent-centric）”的动态对抗。这传递出DeepMind正全力推动AI从“对话工具”向“行动Agent”跨越的强烈信号。
