🌐 原文翻译

衡量迈向通用人工智能（AGI）的进展：一种认知框架

通用人工智能（AGI）有潜力加速科学发现，并帮助解决人类面临的最紧迫问题。但由于缺乏评估系统通用智能的经验工具，我们很难判断距离这一关键里程碑还有多远。追踪AGI的进展需要广泛的方法和途径，我们认为认知科学（Cognitive Science）提供了重要的一块拼图。

因此，我们今天发布了一篇新论文《衡量迈向AGI的进展：一种认知分类法（Cognitive Taxonomy）》，为理解AI系统的认知能力提供了科学基础。配合该论文，我们与Kaggle合作发起了一场黑客松，邀请研究社区帮助构建将该框架付诸实践所需的评估工具。

解构通用智能：我们的框架借鉴了心理学、神经科学和认知科学数十年的研究，提出了一种认知分类法。它确定了10项关键认知能力，我们假设这些能力对AI系统的通用智能至关重要：感知（Perception）、生成（Generation）、注意力（Attention）、学习（Learning）、记忆（Memory）、推理（Reasoning）、元认知（Metacognition，即对自身认知过程的了解与监控）、执行功能（Executive Functions，包括规划、抑制和认知灵活性）、问题解决（Problem Solving）以及社会认知（Social Cognition）。

为了评估这些能力，我们提出了三阶段评估协议：使用留出测试集（Held-out Test Sets）防止数据污染（Data Contamination）来评估AI；从具有人口统计学代表性的成人样本中收集人类基线（Human Baselines）；将AI表现映射到人类表现分布中。

从理论到实践：为了弥补评估差距，我们启动了Kaggle黑客松，鼓励社区针对差距最大的五个领域（学习、元认知、注意力、执行功能和社会认知）设计评估标准，参与者可使用Kaggle新推出的社区基准平台进行构建。

🔬 行业专家解析

从技术与研发一线视角来看，Hassabis 提出的“认知分类法”在学术界和前沿研发团队中具有极高的共识。业内早已苦于“刷榜式”的静态评测（如 MMLU、GSM8K），大家普遍认同当前 LLM 在复杂规划、自我纠错（元认知）和长上下文聚焦（注意力）上存在严重瓶颈。然而，在执行层面，将认知科学概念转化为可计算的 Loss 函数或自动化评测脚本面临巨大挑战。例如，“元认知”要求模型不仅能给出答案，还要能评估自身答案的置信度并主动调用工具验证，这在当前的 RLHF（基于人类反馈的强化学习）范式中极难稳定优化。

在商业与运营落地方面，该框架揭示了当前 AI Agent 商业化被严重低估的关键细节：“社会认知”与“执行功能”。许多企业级 Agent 失败并非因为推理能力差，而是缺乏“执行功能”中的“抑制（Inhibition）”能力——即在不确定时停止行动并请求人类介入，以及缺乏“社会认知”导致在多 Agent 协作或人机交互中产生幻觉和有害操纵。高估了当前模型通过简单 Prompt Engineering 就能获得这些能力的潜力，是过去两年 Agent 创业公司大面积死亡的核心原因。

此外，构建“人口统计学代表性的人类基线”在运营上成本极高且难以标准化。认知能力的评估高度依赖动态上下文，静态的留出测试集（Held-out Test Sets）很容易被模型通过“捷径（Shortcut）”过拟合。因此，行业亟需从静态问答评测转向基于沙盒环境（Sandbox）的交互式、过程性评测，这将是接下来技术攻坚的深水区。

📈 未来趋势展望

基于此信号，在未来 6 个月内，我们预计 Kaggle 黑客松将产出首批针对“元认知”和“执行功能”的开源动态 Benchmark。各大模型厂商（如 OpenAI、Anthropic、Google）将迅速跟进，并在其下一代模型的技术报告（Technical Report）中强制披露这些认知维度的得分。同时，AI IDE 和代码助手产品将开始集成“元认知监控”模块，在代码生成后自动进行自我审查和重构，以展示其在该维度的能力提升。

在 1-2 年的中期演变方向上，AI Agent 的系统架构将发生范式转移。当前的“Prompt + Tool”线性架构将被淘汰，取而代之的是具备“内在元认知监控”和“动态注意力分配”的闭环系统（如基于 System 2 思维的慢思考架构）。在科学发现领域，随着模型“执行功能”的补齐，我们将看到首批由 AI Agent 主导的端到端材料科学或生物学突破，Agent 将能够自主规划长达数周的实验流程并处理异常数据。

然而，这一进程存在显著的不确定性和风险因素。首先，认知科学框架可能过于学术化，导致工业界难以将其转化为高效的工程优化目标，存在“叫好不叫座”的风险。其次，“社会认知”的评估极易陷入文化偏见和价值观对齐的政治争议中，不同地区对“适当的社会反应”定义截然不同，这可能导致全球统一的 AGI 评估标准难以达成，进而引发监管层面的碎片化风险。

💰 投资建议

从资本配置角度来看，Demis Hassabis 此次明确界定 AGI 评估的“五大认知短板”，实质上是为下一代 AI 基础设施的投资指明了方向。当前大模型在“感知、生成、推理”等基础能力上已陷入同质化红海，资本应迅速向“元认知、执行功能、社会认知”等 Agent 核心能力的垂直评测与训练数据赛道倾斜。具体而言，具备高质量人类基线（Human Baselines）数据采集能力、以及专注于复杂逻辑链路标注的数据服务商（如 Scale AI、Snorkel AI 或专注于合成数据与认知对齐的初创公司）将迎来估值重估。

在资产类别与行业影响上，AI Agent 基础设施层（如 LangChain、CrewAI 等编排框架）将因“执行功能”和“注意力”评估标准的落地而获得新的产品迭代方向。投资机会集中在那些能够将“元认知（自我纠错与反思）”工程化并封装为中间件的企业。相反，风险点在于：随着 DeepMind 联合 Kaggle 开源这些认知评估基准，独立第三方 AI 评测公司（如提供静态排行榜的机构）的护城河将被严重削弱，其商业模式面临被大厂“降维打击”的风险。

市场反应路径方面，短期内（1-3个月），Kaggle 黑客松的启动将引发 AI 数据服务与评测板块的炒作，相关概念股或一级市场标的估值上浮；中期（6-12个月），当基于该框架的评测结果公布时，市场将根据各家大模型在“元认知”和“社会认知”上的得分，重新定价大模型厂商的技术壁垒。若某家头部企业在这五项短板中表现显著落后，其 ToB 企业级市场的商业化进程将受挫，引发股价或估值回调。
