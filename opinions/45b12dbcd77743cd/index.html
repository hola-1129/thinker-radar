🌐 原文翻译

Sundar Pichai 指出，Gemini 时代开启近两年来，AI Overviews（AI概览）月活达20亿，Gemini应用月活超6.5亿，超70%的云客户使用AI，1300万开发者使用生成式模型。Gemini 1 突破了原生多模态（native multimodality）和长上下文窗口（long context window）；Gemini 2 奠定了智能体能力（agentic capabilities）基础，Gemini 2.5 Pro 在 LMArena（大模型竞技场）霸榜超六个月。如今推出的 Gemini 3 是最智能的模型，在推理方面达到最先进水平（state-of-the-art），能理解深度与细微差别，精准把握上下文与意图，实现从“读取图文”到“察言观色（reading the room）”的进化。Gemini 3 首日即集成至 Search 的 AI Mode、Gemini 应用、AI Studio、Vertex AI 以及全新的智能体开发平台 Google Antigravity。Demis Hassabis 补充道，这是迈向 AGI 的重要一步，Gemini 3 是全球多模态领域最佳的模型，旨在帮助人类将任何想法化为现实。

🔬 行业专家解析

在技术一线，通过“迭代深化计算推理”来提升模型表现（即 System 2 思考模式）已成为头部 AI 实验室的绝对共识。OpenAI 的 o 系列模型和 DeepMind 的 Deep Think 殊途同归，证明了在预训练数据见顶的当下，通过增加推理阶段的算力来换取逻辑和数学能力的提升，是突破 Scaling Law 瓶颈的最有效路径。这一技术路线在学术界和工业界已无太大争议。

然而，在执行层面，Deep Think 面临着严峻的工程与商业平衡挑战。最大的痛点在于延迟（Latency）和成本（Cost）。在 C 端 Search 场景中，用户对响应速度的容忍度极低，如果 Deep Think 导致搜索响应时间从毫秒级增加到秒级甚至十秒级，将严重损害用户体验。因此，如何在端侧和云侧进行动态算力路由（Routing），让简单问题走快思考，复杂问题走 Deep Think，是极具挑战的工程细节。

行业内普遍高估了 C 端用户为“深度推理”直接付费的意愿，却低估了 B 端 Agent 平台（如 Antigravity）在重塑企业工作流中的破坏力。Deep Think 的真正价值不在于帮普通用户写一封更好的邮件，而在于让 Agent 能够自主进行多步规划、自我纠错和复杂任务拆解。这种从“Copilot（副驾驶）”到“Autopilot（自动驾驶）”的跨越，才是企业级市场愿意支付高昂 API 费用的核心驱动力。

📈 未来趋势展望

在未来 6 个月内，Deep Think 模式将在各类前沿基准测试（如 MATH、GPQA、HumanEval）中刷新记录，尤其是在需要长程逻辑链和复杂代码生成的任务上拉开与竞品的差距。同时，Search 中 AI Mode 的全面上线将引发 SEO（搜索引擎优化）行业的剧烈震荡，传统基于关键词的流量分发逻辑将失效，内容创作者和营销机构必须转向“AI 意图优化（AIO）”，这将催生一批新的 AI 营销 SaaS 工具。

在 1-2 年的中期演变中，基于 Google Antigravity 平台的 Agent 生态将迎来爆发。企业级应用将完成从“对话式 AI”向“行动式 AI（Agentic AI）”的范式转移。我们预计，到 2027 年，大型企业中将有超过 40% 的日常数据处理和初步决策流程由具备 Deep Think 能力的 Agent 自主完成。推理算力（Inference Compute）在整体 AI 算力支出中的占比将历史性地超越训练算力（Training Compute），成为云厂商营收的核心增长引擎。

然而，不确定性与风险同样在积聚。正如 Hassabis 在 [2026-03-25] 所警告的，必须审视“AI 交互对人的影响及潜在的有害操纵”。具备深度推理和长期规划能力的 Agent，如果被恶意利用，其生成高度定制化钓鱼攻击或操纵舆论的能力将呈指数级上升。此外，若推理成本下降曲线不及预期，云厂商可能被迫对 Agent API 进行大幅提价，从而抑制中小企业的创新活力，导致 AI 生态出现“寡头垄断”的僵局。

💰 投资建议

从资本配置角度看，Gemini 3 引入的 Deep Think（深度思考）模式标志着“推理时计算（Test-time compute）”正式成为科技巨头的核心军备竞赛。这直接利好 AI 基础设施赛道，尤其是高性能算力芯片（如 NVIDIA 的 Blackwell 架构）以及 Google 自身的 TPU 产业链。由于迭代深化计算推理需要消耗数倍于传统生成的算力，数据中心的电力、液冷散热及高速光模块需求将迎来新一轮价值重估。

其次，Google Antigravity 智能体开发平台的发布，为企业级 AI Agent 赛道注入了强心剂。投资机会将从底层大模型向中间件和垂直应用层转移。那些能够利用 Antigravity 平台快速构建行业专属 Agent 的 SaaS 公司（如医疗合规、金融风控、复杂代码重构领域）将获得估值溢价。同时，需警惕传统软件公司的“被颠覆风险”，若其未能及时接入新一代 Agent 平台，其市场份额将被原生 AI 创业公司快速蚕食。

市场反应路径方面，短期内 GOOGL 股价将因产品超预期和 Search 首日集成而受到提振，巩固其在 AI 搜索防御战中的护城河。但中长期来看，华尔街将严苛审视“推理成本”对毛利率的侵蚀。如果 Deep Think 模式无法在 B 端实现高客单价转化，市场可能会在 2-3 个季度后对 AI 资本开支（Capex）的 ROI 产生质疑，引发科技股估值回调。

📜 历史言论对比

本次 Gemini 3 及 Deep Think 的发布，是 Demis Hassabis 长期技术愿景的自然延续与战略深化。在 [2026-05-17] 的观点中，他明确提出“科学突破将越来越多地来自通用 AI agent”，并指出“现代科学的瓶颈是手动合成和分析文献”。Gemini 3 强大的深度推理和上下文理解能力，正是为了解决这一复杂信息合成瓶颈而打造的底层引擎，标志着 DeepMind 正在将 AlphaFold 等科学 AI 中验证过的深度推理能力，泛化到通用大模型中。

同时，这一发布也体现了对商业化落地痛点的积极回应。Hassabis 在 [2026-04-21] 曾敏锐指出“企业 AI 采用存在巨大差距，仅 25% 的组织成功将 AI 规模化投产”。Gemini 3 首日即集成 Search，并推出专门的智能体开发平台 Google Antigravity，正是为了降低企业开发门槛，跨越这 75% 的采用鸿沟。从专注前沿研究到提供全栈 Agent 开发平台，这一转变传递出 DeepMind 正在加速从“实验室”向“商业基础设施”转型的强烈信号。
