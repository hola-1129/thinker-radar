🌐 原文翻译

2025年是研究取得非凡进展的一年。在人工智能（AI）领域，我们看到其发展轨迹正从一种“工具（tool）”向“实用设施（utility）”转变：从人们使用的东西，变成可以替人们工作的东西。如果说2024年是为这个时代奠定多模态（multimodal）基础，那么2025年则是AI开始真正与我们一起思考、行动和探索世界的一年。在量子计算（quantum computing）方面，我们向现实世界应用迈出了坚实步伐。全面来看，我们致力于将研究转化为现实，让更强大、更实用的产品和工具在今天就对人们的生活产生积极影响。

今年，我们通过发布Gemini 2.5、Gemini 3及Gemini 3 Flash，在推理（reasoning）、多模态理解、模型效率和生成能力上取得了世界级突破。Gemini 3 Pro在LMArena、Humanity’s Last Exam及GPQA Diamond等基准测试中重新定义了多模态推理，并在MathArena Apex上以23.4%的成绩创下数学领域的新SOTA（state-of-the-art）。随后推出的Gemini 3 Flash结合了Pro级推理与Flash级的低延迟（latency）、高效率，以极低成本实现了超越上一代Pro模型的性能。此外，我们的开源Gemma模型家族也在多模态、长上下文窗口（context window）和多语言能力上取得了显著进展。

🔬 行业专家解析

在AI研发与产品一线，AI从“Copilot（副驾驶/工具）”向“Agent（智能体/实用设施）”的演进已是绝对的行业共识。Hassabis指出2025年是AI“开始真正思考、行动和探索”的一年，这准确描绘了当前大模型从被动响应向主动规划（Planning）和工具调用（Tool-use）转型的技术主线。

然而，在执行层面，将这种“思考与行动”转化为高可靠性的企业级产品仍面临巨大挑战。尽管Gemini 3 Pro在Humanity’s Last Exam等极难基准测试中表现优异，但在真实的长程复杂任务（Long-horizon tasks）中，Agent的错误累积（Error compounding）和幻觉问题依然棘手。企业客户对Agent的容错率极低，这要求我们在工程上引入大量的人类反馈强化学习（RLHF）和确定性规则兜底。

行业内可能低估了Gemini 3 Flash和Gemma开源模型对端侧（Edge AI）生态的颠覆性影响。当顶级推理能力被压缩到极低成本和较小参数量时，手机、PC甚至物联网设备上的本地化Agent将迎来爆发，这将极大缓解云端推理的隐私和延迟痛点。同时，市场可能高估了当前Agent的“完全自主性”，在可预见的未来，“Human-in-the-loop（人在回路）”仍是保证系统安全与合规的必要设计。

📈 未来趋势展望

基于“AI向实用设施转变”及“高性价比推理模型普及”的信号，未来6个月内，我们预计将看到端侧AI（Edge AI）和轻量级Agent应用的爆发。随着Gemini 3 Flash和Gemma多模态开源模型的广泛部署，智能手机和AI PC将内置具备离线复杂推理能力的本地Agent，大幅降低云端API调用成本，相关硬件厂商（如苹果、高通、联想）的AI终端销量将迎来显著增长。

在1-2年的中期演变中，AI在科学发现（Scientific Discovery）领域的Agent系统将实现从“辅助分析”到“自主闭环”的跨越。结合Hassabis对科学研究的关注，我们预测DeepMind将推出专门针对生物、材料科学的自动化Agent平台，这些Agent不仅能综合文献，还能直接调用云端自动化实验室（Self-driving labs）进行假设验证，从而在2027年前后催生首批由AI完全主导发现的临床前药物或新型电池材料。

然而，不确定性和风险因素同样显著。当AI真正开始“替人工作”并具备行动能力时，Agent越权操作、数据泄露以及被恶意利用进行“有害操纵”的风险将急剧上升。如果企业级AI治理框架和监管政策（如欧盟AI法案的细则）未能及时跟上，那“75%未投产的企业”将因合规恐惧而持续观望，从而拖慢整个AI商业化的宏观进程。

💰 投资建议

从资本配置角度看，Demis Hassabis强调AI从“工具”向“实用设施（Utility/Agent）”的转变，以及Gemini 3 Flash带来的“下一代Flash超越上一代Pro”的成本断崖式下降，将深刻重塑AI赛道的投资逻辑。市场资金将从“算力基础设施与基础模型训练”的单一集中，加速向“AI应用层与推理侧算力”扩散。

具体投资机会方面，推理算力需求将因Agent的“行动与探索”呈指数级爆发。尽管单Token成本下降，但总调用量将激增，利好英伟达（NVIDIA）的推理芯片、AMD以及博通（Broadcom）等定制ASIC厂商。在应用层，具备深厚行业Know-how且能利用低成本API构建垂直Agent的SaaS公司（如ServiceNow、Salesforce的AI模块）将迎来估值重估。

风险点在于“套壳”大模型API的初创公司将面临毁灭性打击。当Gemini 3 Flash以极低价格提供顶级推理能力时，缺乏专有数据和工作流护城河的中间层公司利润将被彻底压缩。此外，量子计算虽提及“向现实应用迈进”，但目前仍处于早期，IonQ等概念股波动极大，仅适合作为投资组合中极小比例的风险敞口（Venture-style allocation）。

📜 历史言论对比

结合Hassabis的近期言论，本次2025年底的“技术乐观主义”与他在2026年展现出的“商业与社会审慎”形成了清晰的逻辑闭环。在2025年底，他高调宣布AI已成功转化为具有积极影响的现实产品；但到了2026年4月21日，他明确指出“AI经济潜力与实际企业应用之间存在巨大采用差距，仅25%的组织成功将AI规模化投产”。这表明，技术突破（如Gemini 3的发布）并不等同于商业落地的自然发生，企业级部署的“最后一公里”依然艰难。

此外，2025年底他强调AI开始“行动和探索世界”，这正是他在2026年5月17日提出“科学突破将越来越多来自通用AI Agent”的技术前奏。2025年模型推理能力的跃升，为2026年AI Agent接管“复杂耗时的文献综合与数据分析”奠定了底层基础。

同时，随着AI从工具变为能“替人工作”的Agent，他在2026年3月25日发出的警告——“必须主动审查AI交互对人和社会的影响，特别是潜在的有害操纵”——显得尤为迫切。这种从“追求能力突破”到“关注社会影响与治理”的视角转变，传递出DeepMind在迈向AGI过程中对安全对齐（Safety Alignment）的日益重视。
