AI智能体已能产出可发表级科研成果，人机协作正重塑科研范式。

DH Demis Hassabis 2026-02-09 原文：Accelerating Mathematical and Scientific Discovery

🌐 原文翻译

在专家数学家和科学家的指导下，Gemini Deep Think 正在解决数学、物理和计算机科学领域的专业研究问题。2025年夏，Gemini Deep Think 的高级版本在国际数学奥林匹克竞赛（IMO）中达到金牌标准，随后在更新版本中于国际大学生程序设计竞赛（ICPC）取得类似成绩，证明其能推理学生级别的顶级难题。此后，该模式进入科学、工程和企业工作流，应对更复杂的开放式挑战。上周，团队发表了两篇论文，详述了跨学科使用 Gemini Deep Think 解决专业研究问题的努力。

在纯数学前沿，研究级数学需要海量文献中的高级技术。为解决基础模型在高级学科中因数据稀缺导致的浅层理解和幻觉（hallucinations）问题，我们构建了名为 Aletheia 的数学研究智能体（Agent）。它由 Gemini Deep Think 驱动，具备自然语言验证器（natural language verifier）以识别候选方案的缺陷并迭代修正。关键在于，该智能体能够“承认失败”，大幅提升了研究者的效率。此外，它利用搜索和网页浏览导航复杂研究，防止合成文献时出现虚假引用和计算错误。

自2025年7月达到IMO金牌标准以来，随着推理时计算（inference-time compute）的扩展，Gemini Deep Think 在 IMO-ProofBench Advanced 测试中得分高达90%。我们证明，在推进到博士级别练习时，缩放定律（scaling law）依然成立。Aletheia 已在研究级数学中实现多项进展：包括无人类干预生成计算算术几何特征权重（eigenweights）论文的可靠自主研究；证明独立集（independent sets）相互作用粒子系统边界的人机协作研究；以及对 Bloom 的 Erdős 猜想数据库中700个开放问题的广泛半自主评估。

🔬 行业专家解析

在AI与科研交叉的一线领域，Hassabis 提出的“AI实现可发表质量研究”具有极高的技术含金量，但业内对此的共识仍存在分层。对于AI解决IMO或ICPC等“有标准答案”的封闭问题，业界早已达成共识；但对于“研究级数学和科学”这种开放式、前沿性问题，此前多数专家认为大模型受限于幻觉和逻辑断层，只能做辅助。DeepMind 通过 Aletheia 引入“自然语言验证器”和“承认失败”机制，精准击中了科研容错率极低的痛点，这在技术路线上获得了顶尖学者的高度认可。

然而，在执行层面，该模式面临巨大的工程与运营挑战。被外界低估的一个关键细节是“跨学科验证器的构建成本”。数学可以通过形式化验证或自然语言逻辑验证，但物理、化学和生物等实验科学，其验证器必须与“湿实验（Wet Lab）”或高精度物理仿真引擎（如分子动力学模拟）深度绑定。目前 Aletheia 主要展示了纯数学和计算机科学的成果，若要扩展到材料科学或合成生物学，构建高保真度的环境反馈闭环（Environment Feedback Loop）将耗费极高的研发成本。

此外，业内可能高估了当前AI Agent的“自主性”。Hassabis 强调这是在“专家数学家和科学家的指导下”进行的，且分为“无干预、AI引导协作、半自主”三个层级。在实际科研运营中，顶级科学家的时间极其宝贵，如果AI Agent 需要专家花费大量时间去“指导”和“纠错”，其作为“力量乘数（Force Multiplier）”的ROI（投资回报率）在初期可能并不理想。真正的拐点在于Agent能否实现长程任务规划（Long-horizon planning），而不仅仅是单点问题的迭代修正。

📈 未来趋势展望

基于此次 Gemini Deep Think 和 Aletheia 的发布，预计在未来 6个月内，DeepMind 将推出针对顶尖高校和国家级实验室的“科研Agent受限API”或闭门测试计划。学术界将迎来一波“AI共著论文”的小高峰，arXiv 上由大模型辅助生成的理论推导论文数量将显著增加。这不可避免地会引发全球学术界关于“AI作者署名权”、“同行评审标准”以及“学术灌水”的激烈辩论，部分顶级期刊（如 Nature, Science）可能会在年内紧急出台针对AI生成科研内容的披露与限制新规。

在 1-2年的中期演变 中，AI for Science 将从目前的“纯理论推导与文献综合”全面向“实验设计与湿实验闭环”进军。DeepMind 极大概率会推出结合自动化机器人实验室（Robotic Labs）的端到端科研Agent，使AI不仅能提出假设，还能自主设计实验参数、控制机械臂执行并分析结果。此外，“推理时计算（Inference-time compute）”的优化将成为大模型公司的核心竞争壁垒，模型架构将从单纯追求参数规模，转向追求在推理阶段动态分配算力的“系统2（System 2）”思考能力。

不确定性和风险因素 方面，最大的风险在于“可发表质量”与“高影响力突破”之间的鸿沟。如果未来1-2年内，AI Agent 只能持续产出“增量型（Incremental）”的普通论文，而无法在诸如室温超导、靶向蛋白降解等硬核领域取得 Hassabis 所期待的“里程碑式突破”，资本市场对 AI4S 赛道的耐心将迅速耗尽，导致估值泡沫破裂。此外，科学界对AI黑盒推理过程的“可解释性”要求，也可能成为限制其在高风险科研领域大规模部署的隐性瓶颈。

💰 投资建议

从资本配置角度来看，Demis Hassabis 此次释放的信号标志着“AI for Science (AI4S)”赛道正式从“概念验证”迈入“生产力转化”阶段。首当其冲受益的是AI研发外包与科技服务赛道。传统CRO（合同研究组织）如药明康德、Charles River等面临估值重塑风险，若不能迅速集成类似Aletheia的AI Agent工作流，其人力密集型商业模式将被颠覆。相反，积极拥抱AI的TechBio公司（如Recursion Pharmaceuticals、Isomorphic Labs）将获得显著的估值溢价。

其次，推理算力基础设施（Inference Infrastructure） 将迎来爆发式增长。Hassabis 明确提到“推理时计算（inference-time compute）的扩展”以及“更低的推理时计算实现更高推理质量”，这意味着大模型的竞争焦点正从训练端（Training）向推理端（Inference）转移。投资者应重点关注在推理芯片和架构上有独特布局的公司，如 Groq、Cerebras，以及 NVIDIA 针对推理优化的 Blackwell 架构产品线。同时，提供高质量科学数据清洗和垂直领域RAG（检索增强生成）服务的中间件公司也将迎来并购热潮。

市场反应路径方面，短期内（1-3个月）资本市场会因“AI写出专业论文”的噱头炒作AI Agent概念股，导致相关板块波动加剧。但作为资深投资人，必须警惕Hassabis文中“尚未声称有里程碑式突破”的严谨定调。中期来看，市场将迅速回归理性，资金会向那些能证明AI Agent不仅能“发论文”，还能切实推进新药管线（IND申报）或新材料量产的“闭环验证”企业集中。未能实现商业闭环的纯AI4S初创公司将面临融资寒冬。

📜 历史言论对比

结合 Demis Hassabis 在2026年上半年的言论轨迹，本次2月9日的观点是其后续一系列宏大战略的技术基石与前奏。在2月，他务实地展示了 Aletheia 在数学和科学中的具体落地，并严谨地指出“尚无里程碑式突破”；这为他在 [2026-05-17] 提出的“科学突破将越来越多来自通用AI agent”以及“AI应作为人类科学创造力的乘数”提供了坚实的技术背书。2月的“可发表质量”是5月“主导科学突破”的必经阶梯。

同时，这一观点与他在安全和伦理层面的考量一脉相承。2月强调通过“自然语言验证器”防止幻觉和虚假引用，正是对 [2026-04-21] 强调的“AI必须负责任地扩散”以及 [2026-03-25] 关注的“防范有害操纵”在科研领域的具体实践。Hassabis 的思想并未发生矛盾或突变，而是呈现出清晰的“技术突破（2月）-> 伦理与社会影响审视（3月）-> 产业落地反思（4月）-> 科学愿景升华（5月）”的演进路线。

这种演变传递出一个强烈信号：DeepMind 正在刻意压制市场对“AGI瞬间颠覆一切”的狂热预期，转而采取“高举高打、严谨验证”的策略。通过在要求最严苛的纯数学界建立信任，再降维向企业级市场渗透，这也解释了为何他在 [2026-04-21] 会指出“企业采用存在巨大差距（仅25%规模化）”——因为真正的科研级AI工具门槛极高，普通企业尚未准备好承接这种深度的“人机协作模型”。
